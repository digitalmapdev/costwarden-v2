# CostWarden V3 — interactive concept

Standalone static prototype for a test GitHub repository.

## Deploy
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, deploy from the main branch/root.
4. Open the generated GitHub Pages URL.

No build step, npm install, framework or backend is required.

## Files
- `index.html` — page structure and copy
- `styles.css` — full visual system + responsive behavior
- `app.js` — interactive spend analysis, sticky story, selectors and motion
- `assets/icons/` — CostWarden favicon/app icons from the existing project

## Important
The demo form intentionally does not submit. Connect the production form endpoint only after the concept is approved.
